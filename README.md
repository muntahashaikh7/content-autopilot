# content-autopilot

Muntaha ke 3 content lanes ka daily pre-production — **MUFT GitHub Actions** par.
Maqsad: uske tokens par **zero** bojh; roz subah briefs/packs repo me ready.

## Lanes (roz subah PKT)
| Workflow | Time | Output |
|---|---|---|
| Couple Reels | 05:00 | Story brief (reverse-engineered-prompt method) + SEO + IG keyword-block captions |
| Nostalgia 3D | 05:30 | Memory-topic brief (relatable-memory mechanics) + YT tags + keyword comment + pin |
| Naba Decor | 06:00 | Marketing pack (v4 VO script + IG/FB captions + pin titles + claims check) |

## Design rules
- **Quality:** competitors ko MATCH ya BEAT — bekaar output kabhi nahi.
- **Reliability:** free sources only, graceful skip on block, run kabhi fail nahi hota.
- **No secrets:** repo me koi key/token nahi.
- **Video generation is phase me nahi** — sirf uske ird-gird ka pre-production.

## Standing laws (encoded)
- IG: keyword-block captions, NO hashtags. Hashtags sirf YT/FB.
- Couple: Zayn & Mira leads, F1-F4 rotation, tasteful romance only.
- Naba: text me "NABA Decor" OK; voiceover me sirf "2 Tier"/"S-Curve". Sirf allowed claims.
- Output: `daily/YYYY-MM-DD/` me briefs (md + json).
